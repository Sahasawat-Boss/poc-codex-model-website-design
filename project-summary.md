# Nordveil

Nordveil is a set of four landing page concepts for an infrastructure monitoring service aimed at growing engineering teams.

## About This Project

The pages introduce how Nordveil could help teams see service relationships, follow unusual signals, and respond to incidents with shared context. Visitors can explore three feature areas, read the proposed workflow, compare three sample pricing tiers, and use contact links to draft an email. Each design adapts to desktop and mobile screens; the most interactive version also lets visitors switch an illustrated system map between normal and incident states.

These are marketing page concepts. The service map, customer logos, pricing, and contact address are illustrative; the pages do not display live infrastructure data or provide a working monitoring platform.

## Tech Stack

- **Frontend:** HTML5, CSS3, inline SVG, and vanilla JavaScript.
- **Contact links:** Browser `mailto:` links using a placeholder email address.
